# Contributing to Simple Interest Calculator

We welcome all contributions to this project!

## How to Contribute

### 🐛 Bug Reports
If you find a bug, please create an issue with detailed information about the problem.

### 🔧 Bug Fixes
We welcome pull requests that fix bugs. Please ensure your fix is well-tested.

### 📚 Documentation Improvements
Improvements to documentation, comments, and README are always appreciated.

### ✨ Enhancements
Have an idea to make this calculator better? We'd love to hear it!

### 💡 Ideas
All ideas for new features are welcome. Please open an issue to discuss before implementing.

## Getting Started
1. Fork the repository
2. Create a new branch
3. Make your changes
4. Submit a pull request

Thank you for contributing! 🎉
